# Cloudflare (zone `mazuryktech.com`, Free plan)

Managed by `terraform/cloudflare`, provider v5. The token comes from Vault secret `core-secret-cf-api-token`, which has three scopes on this zone only:
- DNS Edit
- Zone Settings Edit
- SSL and Certificates Edit

## What Terraform owns

| Item | Value |
|---|---|
| `A mazuryktech.com` | `203.0.113.10` (reserved `core-pip-nlb`), **proxied** |
| `A *.mazuryktech.com` | same, **proxied**. Covers every project and tool hostname |
| `TXT mazuryktech.com` | `v=spf1 include:eu.rp.oracleemaildelivery.com ~all` (DNS only) |
| `CNAME core-dkim._domainkey` | `core-dkim.mazuryktech.com.dkim.lhr1.oracleemaildelivery.com` (DNS only) |
| `TXT _dmarc` | `v=DMARC1; p=none; rua=mailto:<alerts>` (monitor only) |
| SSL/TLS mode | **Full (strict)** |
| Always Use HTTPS / Automatic HTTPS Rewrites | on / on |
| Minimum TLS | 1.2 |
| Origin CA certificate | RSA, `*.mazuryktech.com` + `mazuryktech.com`, 5475 days (expires 2041-10-09). The key and CSR are generated by `tls_private_key`. Both are stored in Vault (`core-secret-cf-origin-cert`/`-key`) |

Notes:
- The provider's `cloudflare_zone_setting` resources cannot be destroyed. Removing them from code leaves the setting as it is.
- The Origin cert `hostnames` list is written in the order the API returns (`["*.domain", "domain"]`) to avoid a perpetual replace.

## Common tasks

| Task | How |
|---|---|
| Change a record or setting | edit `terraform/cloudflare/*.tf`, then `make plan-cloudflare apply-cloudflare` |
| Add a manual record (e.g. a verification TXT) | prefer adding it to `dns.tf`. Records made by hand in the dashboard are not removed by Terraform, but they are not tracked either |
| Rotate the Origin cert | `make apply-cloudflare ARGS='-replace=tls_private_key.origin'`, then `make host-sync VM=cloud` |
| Rotate the API token | roll it in the dashboard, then `make secret-put NAME=core-secret-cf-api-token` |
| Cloudflare IP ranges changed | the weekly drift cron emails you. Fix with `make plan-core apply-core` (the NSGs are built from the live list). Check with `make drift` |
| Another domain | add the zone, proxy it to the same IP, add an Origin cert and a Caddy `tls` snippet. See [web-projects](web-projects.md) |
| Email Routing (optional, free) | enable it in the dashboard to forward e.g. `me@mazuryktech.com`. Merge its SPF with the existing TXT; don't create a second SPF record |

## Free-plan limits

- Requests time out after about 100 s.
- Uploads are capped at 100 MB.
- WebSockets are fine.
- WAF managed rules and rate limiting are limited to the free tier.

## Debug

```bash
curl -sI https://mazuryktech.com                       # cf-ray header = proxied
curl -s https://mazuryktech.com/cdn-cgi/trace          # edge info
dig +short mazuryktech.com                             # Cloudflare anycast IPs, not 203.0.113.10
```

| Error | Meaning |
|---|---|
| 521 | origin refused the connection (Caddy down or NSG) |
| 522 | timeout (NLB/NSG path) |
| 525/526 | TLS handshake or invalid cert at origin (wrong or missing Origin cert in `/data/core/edge/certs`) |
